# CatTinder

*CatTinder* — мобильное Flutter-приложение, в котором можно свайпать случайных котиков, ставить лайки и смотреть подробную информацию о породах.

Приложение использует публичное API TheCatAPI.

## Описание проекта

Приложение состоит из двух основных вкладок:

### Кототиндер

- На главном экране появляется случайный котик определённой породы.
- Котика можно свайпнуть вправо/влево или нажать на кнопки «Лайк» / «Дизлайк».
- При свайпе/лайке/дизлайке загружается новый кот.
- Счётчик лайков сохраняется при переключении вкладок.
- При нажатии на фото открывается экран с детальной информацией о породе.

### Список пород

- Отображается полный список пород, полученных из API.
- По нажатию открывается подробная карточка породы с описанием и характеристиками.

## Реализованные фичи

### Основные

- Загрузка случайного котика по выбранной случайной породе
- Отображение названия породы
- Свайпы влево/вправо
- Кнопки «Лайк» / «Дизлайк»
- Счётчик лайков
- Открытие детального описания по нажатию на фото
- Отображение списка пород с подробной карточкой
- Обработка сетевых ошибок (AlertDialog)

### Технические

- HTTP-запросы через пакет http
- Кэширование списка пород
- Модельные классы для котиков и пород
- Image + CachedNetworkImage
- Навигация через Navigator.push
- Кастомная иконка приложения
- Clean Architecture (Data/Domain/Presentation слои)
- Dependency Injection с GetIt
- Авторизация (регистрация и вход)
- FlutterSecureStorage для безопасного хранения паролей
- Множество пользователей на одном устройстве
- Онбординг показывается один раз за пользователя
- Unit-тесты (11+ тестов)
- Provider для state management

### Стиль и качество кода

- Подключён flutter_lints
- Код полностью проходит flutter analyze
- Отформатировано через dart format
